# Http_benchmark
Асинхронный инструмент для нагрузочного тестирования HTTP-серверов. 
**Не требует установки внешних библиотек**
## Запуск
```bash
python bchhttp.py -H https://yandex.ru -C 10
```

## Аргументы командной строки
| Аргумент | Описание |
| :--- | :--- |
| `-H`, `--host` | URL тестируемого хоста |
| `-C`, `--count` | Количество запросов к хосту (по умолч. 1) |
| `-F`, `--file` | Путь к файлу со списком URL-адресов (по одному на строку) |
| `-O`, `--output` | Сохранить результат в указанный файл вместо вывода в консоль |
```
